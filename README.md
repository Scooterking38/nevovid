```
# Nevorid: A Python Package for Creating Interactive Visualizations
A library for generating mesmerizing graphics using pygame, numpy, and imageio.

## Features
* Creates interactive visualizations using pygame and numpy.
* Supports video output through imageio [ffmpeg].

## Tech Stack
* Primary Language: Python
* Libraries:
	+ Pygame
	+ NumPy (>=1.22.0)
	+ Imageio [ffmpeg] (>=2.31.0)

## Installation

To get started, simply install the required dependencies using pip:
```
pip install -r requirements.txt
```
Run `python demo.py` to see a sample visualization in action.
```
